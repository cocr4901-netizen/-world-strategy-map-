ABOUT THIS PROTOTYPE

Explore the world one place at a time.

This map is a working, offline-capable research prototype—not a deployed live-news, transport or military tracker. Six country profiles contain approximate figures carried over from the earlier October 2026 research reports and still require independent source-series verification. They are illustrative, not current live measurements.

Political geometries and basic location names are adapted from the countryinfo Python package (MIT license), an older and incomplete geography set. It includes territories and may not accurately reflect disputed boundaries or recent political changes. Unmapped places can be added later using authoritative geography.

Version 0.9 adds a Trade & Supply Chains Lab with fictional example partner flows, route-mode filtering, process-stage navigation and a labeled optional map overlay. Version 0.8 added a curated regional drill-down, map lens explorer and visual evidence-status guide in the Command Center. Only some sample cities have region labels; no state/province boundaries or complete regional datasets are included. Earlier versions added the conceptual technology/civics Command Center, diplomacy UI mock and output catalog. No new country measurements are asserted. Previous versions add more curated city points, city reference panels, selected historical 2020 U.S. city census population references (not independently rechecked in this build), and example civil resource/infrastructure pins with approximate locations. The map is not a comprehensive updated registry of ports, mines or power plants. It does not track aircraft, ships, resource production or live military forces.

The planned Technology, Civics, Trade, News, and Military layers are indicated as future research areas, not fabricated datasets. No personally identifying live travel or sensitive operational military movements are tracked.

All code is plain HTML, CSS and JavaScript. No API keys, accounts, paid service, or network access is needed to open the map files locally.
